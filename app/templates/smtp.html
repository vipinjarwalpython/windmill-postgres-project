{# ----- Troubleshooting ----- #}

Troubleshooting

Common SMTP failure modes and how to fix them.

Authentication failed
Gmail & Outlook reject your account password. Generate an App Password at myaccount.google.com/apppasswords and use that as SMTP_PASSWORD. Two-factor auth must be on first.
Could not connect / timeout
Check SMTP_HOST and SMTP_PORT are correct (Gmail: smtp.gmail.com:587). Make sure the container has outbound internet.
TLS error
Use port 587 with STARTTLS, or port 465 for implicit SSL. Don't mix.
Changed .env but nothing happened?
Run docker compose up -d --force-recreate api. A plain restart reuses the old env snapshot.
